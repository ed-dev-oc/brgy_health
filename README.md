# Rails 8 Application

This is a Ruby on Rails 8 application.

## Ruby version

- Ruby 3.3.6

## Rails version

- Rails 8.0.2

## System dependencies

- Node.js (>= 18.16.0)
- Yarn (>= 1.22.22)
- PostgreSQL (>= 17.4)

## Services

- Solid Trifecta (Solid Cable, Solid Cache, Solid Queue) 

## Installation

- `git clone https://github.com/ed-dev-oc/brgy_health.git`
- `cd brgy_health`
- `rails db:create`
- `rails db:migrate`
